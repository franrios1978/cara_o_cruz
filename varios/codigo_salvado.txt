- Moneda: imágenes JPG reales de `src/varios` (`moneda_cara.jpg` y `moneda_cruz.jpg`,

- Accesibilidad: botón deshabilitado durante el turno, mensaje con `aria-live`,
  soporte para `prefers-reduced-motion`.

Fase 3 — Lógica, aleatoriedad y sonido
--------------------------------------
`src/modules/random.js`:
- `getRandomResult()`: lee 1 byte con `globalThis.crypto.getRandomValues` y devuelve
  `"cara"` si el bit 0 está a 0 y `"cruz"` si está a 1. Al usar un solo bit de un byte
  aleatorio criptográfico no hay sesgo por módulo.

`src/modules/sound.js`:
- `audioContext` se crea de forma perezosa con `AudioContext`/`webkitAudioContext`.
- `getAudioContext()`: reanuda el contexto si está `suspended`; devuelve `null` si la
  API no existe, para que la web siga funcionando sin sonido.
- `playTone({ frequency, duration, type, gain, detune })`: oscilador + envolvente
  exponencial; ataque de 4ms y decaimiento hasta 0.0001.
- `playNoise({ duration, gain, filterFrequency, resonance })`: buffer corto de ruido con
  envolvente y filtro `bandpass` (Q 1.2 por defecto); simula el contacto con el suelo.
- `playLaunchSound()`: "clin" inicial con parciales de 2100 Hz (sine), 3150 Hz
  (triangle, +8 cents) y 4300 Hz (sine).
- `playLandingSound()`: impacto metálico agudo con parciales inarmónicos de 1180 Hz
  (sine), 1770 Hz (sine, +12 cents), 2630 Hz (triangle, -18 cents) y 3980 Hz (sine),
  con decaimientos de 130/100/75/50 ms y ruido filtrado a 5200 Hz (Q 5) durante 50 ms.

`src/main.js`:
- Referencias: `.coin-stage`, `#coin`, `#throw-button` y `#result`.
- Constantes: `TURN_DURATION = 1250` (idéntico a `--toss-duration` en CSS),
  `FINAL_ROTATIONS` (`cara` → `0deg`, `cruz` → `180deg`) y `MESSAGES`
  (`¡Ha salido cara!` / `¡Ha salido cruz!`).
- `waitForLanding()`: promesa que resuelve al recibir `animationend` de `spin` en
  `#coin`; incluye un `setTimeout` de seguridad de 1450ms para no bloquear el turno.
- `throwCoin()`: ignora clicks con el botón deshabilitado; limpia el mensaje, obtiene
  el resultado, fija `--final-rotation`, reproduce el clin, fuerza un reflow con
  `void stage.offsetWidth`, cambia el estado a `tossing`, espera la caída, reproduce
  el impacto, cambia a `result`, muestra el mensaje y rehabilita el botón.
- Evento: `button.addEventListener("click", throwCoin)`.

Flujo de estados
----------------
`idle` → (click) → `tossing` → (animationend de `spin` o timeout) → `result`
→ (nuevo click) → `idle`.
